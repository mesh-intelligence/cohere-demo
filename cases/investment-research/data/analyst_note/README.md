# analyst_note

**Every note here is invented.** The issuers, deals, people, and views are fictional,
written so access-gated retrieval has something to gate. No note makes a claim about a
real company, and none is investment advice.

## Levels

Each note declares the barrier it sits behind, and the manifest maps that onto the
mesh's ordered set. Twenty-eight notes span the three levels above Public, so every access
pair has material to withhold.

## The guard

An invented "non-public" claim about a real company would be a fabricated claim about a
real issuer. The build fails if a note names a `filing_facts` issuer, one of its
tickers, or anything in `real-entities.yaml`, and it fails if a note uses the language
of a recommendation.

The invented names were checked on 2026-11-02 against the SEC's list of 10,423
registrants with tickers, and none matched. That list omits private companies, so this
lowers the chance of a collision and does not rule one out. A name that turns out to
belong to someone is a defect to fix by renaming it here.
